# 作業ログ: 2026-10-01 (v1.0.0.46〜v1.0.0.50) - ゾンビスポーン挙動・仮想ホード刷新 ＆ サンドボックス動的同期

## 1. 概要
本セッションでは、Project Zomboid Build 42 MOD「Exclusion Zone Trader (B42)」において、物資投下ヘリに伴うゾンビホードのスポーン挙動とサンドボックス設定のリアルタイム同期に関する5件の重要課題を解決・最適化した。

## 2. 実施内容

### 2.1 プレイヤー周辺スポーン絶対セーフティ (v1.0.0.46)
- **課題**: プレイヤーがLZから離れた位置にいると、LZ基準35タイルの地点がプレイヤーからわずか15タイルの至近距離になり、目の前に直接ポップする問題が発生していた。
- **改修**:
  - `PLAYER_SAFETY_RADIUS_TILES = 45` を導入。
  - `getActivePlayers()` で全生存プレイヤーを取得し、どのプレイヤーからも45タイル（画面外保証）以上離れたマスのみにスポーンを許可。
  - `HORDE_SPAWN_RADIUS_MIN` を 35 -> 45 に引き上げ。
  - 安全マスがない場合は無理に湧かせず予約キューへ自動退避。

### 2.2 ヘリ飛行ルート連動 ＆ コーン進入角鋭角化 (v1.0.0.47)
- **課題**: コーン拡散角度が +/-60度（120度）と広すぎ、拠点の側面からも湧いて挟み撃ちに見えていた。
- **改修**:
  - コーン角度を `+/-30度`（合計60度のシャープな進入回廊）に絞り込み。
  - ヘリ距離とスポーン半径を連動（遠方時: 85〜120タイル、接近時: 50〜85タイル）。

### 2.3 遠隔チャンクへの仮想ホード (Popman) 最優先配置 (v1.0.0.48)
- **課題**: デバッグ画面「ゾンビ人口分布」の解析により、未ロード空間には実体配置できないため、プレイヤーのメモリロード枠（白い四角）の境界線ギリギリに黄色い点（実体）が集中ポップしていたことが判明。
- **改修**:
  - ヘリ接近中、すべてのゾンビをヘリ現在地 `(heli.x, heli.y)`（未ロード遠隔チャンク）を起点として `ZombiePopulationManager:createHordeFromTo` で発進。
  - ロード枠境界へのポップを完全に根絶。遠隔チャンクから歩行して白い枠を越えた瞬間にバニラエンジンが自動で実体化させる自然な大群移動を実現。
  - 仮想配置失敗時のみ、安全距離実体スポーンにフォールバック。

### 2.4 デフォルト設定を遠隔100%（仮想ホードのみ）に変更 (v1.0.0.49)
- サンドボックス設定 `HeliHordeRemoteRatio` のデフォルト値を option 5（遠隔のみ 100% / 近接 0%）に変更。
- 通常ゲームプレイにおいて、ロード枠フチへの直接湧きがゼロになる設定を標準化。

### 2.5 ゲーム内サンドボックス設定変更のリアルタイム動的解決 (v1.0.0.50)
- **課題**: ゲーム中に管理画面等でホード規模を変更しても、古い `SandboxVars` がキャッシュされ、ゲーム開始時の設定（狂気など）が固定されて変更が反映されない問題。
- **改修**:
  - `RadioTrader_Config.getSandboxOption` の解決順序を逆転させ、Java API `getSandboxOptions():getOptionByName(...)` を最優先で取得。
  - 最新値を Lua の `SandboxVars.RadioTrader[key]` にも即座に同期・上書き。再起動なしで次のヘリから最新規模が即座に反映されるよう改善。

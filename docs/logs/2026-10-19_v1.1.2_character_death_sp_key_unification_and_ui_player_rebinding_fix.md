# 2026-10-19 v1.1.2 キャラクター死亡時のSP共通キー統一およびUIプレイヤー再バインド・旧データ自動救済

## 1. 概要と背景
PENDING（配達待ち）中にプレイヤーが死亡し、同じワールド内で新キャラクターを作成してプレイを再開した際、以下の不具合が発生し取引システムが完全にスタックする現象を確認した。

1. **画面の膠着（UIが旧キャラのデータを上書き）**:
   - 取引画面（`RadioTrader_UI`）の右上に「配達状況: PENDING (0h 00m)」と表示され、発注ボタンが無効化（グレーアウト）されたまま動かない。
2. **コンテナに投下要請が出現しない**:
   - 新キャラクターでドロップボックス（LZ）を見ても、`[Drop] 投下要請` が出現せず、`[LZ] LZ登録を解除` のみ表示される。
3. **ログ上の不整合**:
   - クライアントログでは `stateRefresh: state=NONE` が返ってきているにもかかわらず、画面表示は `PENDING` のまま固定化されていた。

実機ログ（`console.txt`）およびコード解析を行った結果、**「UIのプレイヤー参照更新漏れ」**と**「シングルプレイ環境におけるModDataキーのキャラクター姓名依存」**が複合して発生していたことが判明したため、根本修正を実施した。

---

## 2. 根本原因の解析

### ① UIインスタンスの旧プレイヤー参照キャッシュ漏れ
`RadioTrader_UI` は一度生成されるとメモリ上にシングルトン（`RadioTrader_UI.instance`）として保持される。
新キャラクターで無線機を開いた際、`RadioTrader_UI.open(player)` の `else` 節（既存インスタンス再表示）において `self.player = player` の更新が行われていなかった。
その結果、UIは30フレームごとの自動更新処理（`refreshDataFromModData`）で、死んだ旧キャラクター（マリオカーペンター）の姓名を元にModDataを読み続け、旧キャラの残高（3444 CR）とタイマー状態（PENDING 0h 00m）で毎フレーム画面を上書きし続けていた。

### ② シングルプレイでのModDataキー分断
PZシングルプレイ環境において、`player:getUsername()` はアカウント名ではなく「キャラクターの姓名」を返していた。
そのため、旧キャラが発注した注文・タイマーは `RadioTrader_マリオカーペンター` に保存され、新キャラは `RadioTrader_アイゼアマーカム` を参照していたため、サーバー側では「新キャラは未注文（`state=NONE`）」と判定され、注文とタイマーが旧キャラ名の下に取り残されていた。

---

## 3. 実装内容

### ① プレイヤー識別キーの共通ヘルパー新設 (`RadioTrader_Config.lua`)
シングルプレイ時はキャラクターの姓名に関わらず固定で `"singleplayer"` を返し、マルチプレイ時のみアカウント名を返す `RadioTrader_Config.getPlayerKey(player)` を新設。

```lua
function RadioTrader_Config.getPlayerKey(player)
    if isClient() or isServer() then
        if player and player.getUsername then
            local uname = player:getUsername()
            if uname and uname ~= "" then
                return uname
            end
        end
    end
    return "singleplayer"
end
```

### ② UIのプレイヤー参照更新とステート同期強化 (`RadioTrader_UI.lua`, `RadioTrader_ClientBridge.lua`)
- `RadioTrader_UI.open(player)`: 既存インスタンス再オープン時にも `RadioTrader_UI.instance.player = player` を確実に実行。
- `RadioTrader_UI:refreshDataFromModData()`: `RadioTrader_Config.getPlayerKey(self.player)` で `"singleplayer"` の最新データを参照。
- `RadioTrader_ClientBridge.lua`: サーバーからの `stateRefresh` 受信時に `RadioTrader_UI.instance:onServerNotify("stateRefresh", args)` を転送。

### ③ 孤立注文データの自動救済マイグレーション (`RadioTrader_ServerEngine.lua`)
シングルプレイ起動時、ModData テーブル群を走査し、過去の旧キャラ名（`RadioTrader_<名前>`）で取り残された注文・タイマーを自動検知して `RadioTrader_singleplayer` および `RadioTrader_Timer_singleplayer` へ引き継ぐマイグレーション処理を追加。

```lua
local function migrateLegacySingleplayerData(player)
    if isClient() or isServer() then return end
    local spGmd = ModData.getOrCreate("RadioTrader_singleplayer")
    local spTimer = ModData.getOrCreate("RadioTrader_Timer_singleplayer")

    if spGmd[RadioTrader_Config.KEY_ORDER] or (spTimer.state and spTimer.state ~= RadioTrader_Config.STATE_NONE and spTimer.state ~= RadioTrader_Config.STATE_COMPLETED) then
        return
    end

    if not ModData.getTableNames then return end
    local tableNames = ModData.getTableNames()
    if not tableNames then return end

    for i = 0, tableNames:size() - 1 do
        local tblName = tableNames:get(i)
        if tblName and tblName ~= "RadioTrader_singleplayer" and string.find(tblName, "^RadioTrader_") and not string.find(tblName, "^RadioTrader_Timer_") and not string.find(tblName, "^RadioTrader_Daily") then
            if ModData.exists(tblName) then
                local oldGmd = ModData.get(tblName)
                if oldGmd and oldGmd[RadioTrader_Config.KEY_ORDER] then
                    log("Migrating orphaned order from legacy table: " .. tostring(tblName) .. " -> RadioTrader_singleplayer")
                    for k, v in pairs(oldGmd) do
                        if spGmd[k] == nil then spGmd[k] = v end
                    end
                    local unamePart = string.sub(tblName, 13)
                    local oldTimerName = "RadioTrader_Timer_" .. unamePart
                    if ModData.exists(oldTimerName) then
                        local oldTimer = ModData.get(oldTimerName)
                        if oldTimer then
                            log("Migrating orphaned timer: " .. tostring(oldTimerName) .. " -> RadioTrader_Timer_singleplayer")
                            for tk, tv in pairs(oldTimer) do
                                spTimer[tk] = tv
                            end
                            oldTimer.state = RadioTrader_Config.STATE_COMPLETED
                        end
                    end
                    oldGmd[RadioTrader_Config.KEY_ORDER] = nil
                    break
                end
            end
        end
    end
end
```

### ④ 全スクリプトのキー参照を統一

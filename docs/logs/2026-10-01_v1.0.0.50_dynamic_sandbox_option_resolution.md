# 作業ログ: 2026-10-01 (v1.0.0.50) - ゲーム内サンドボックス設定変更のリアルタイム動的解決機構

## 1. 概要
- **ユーザーフィードバック**: 「ヘリ追従ホード規模のオプション設定がゲーム中に切り替えても変更されてないかもしれない。もしかして、固定で最大規模？ コード確認」
- **原因**:
  - PZエンジンではゲーム中に管理者メニューやサンドボックス変更画面で設定を変更した際、Javaの `SandboxOptions` は即座に更新されるが、Luaグローバルの `SandboxVars` はゲーム再起動まで古い値のまま残ることがある。
  - `RadioTrader_Config.getSandboxOption(key)` が古い `SandboxVars` を最優先で読み込んでいたため、ゲーム中に変更しても常に古い起動時の値が返されていた。

## 2. 実施内容
- `RadioTraderMod/42/media/lua/shared/RadioTrader_Config.lua`:
  - `getSandboxOption` の解決順序を逆転させ、**Java API `getSandboxOptions():getOptionByName(...)` を最優先** で取得するように改修。
  - Java側から最新値が取得できた場合、Luaの `SandboxVars.RadioTrader[key]` にも即座に値を同期・書き戻し。
  - ゲーム中に管理画面等でホード規模（小規模〜狂気）や他のオプションを変更した際、再起動なしで次のヘリイベントから即座に最新設定が反映されるよう修正。

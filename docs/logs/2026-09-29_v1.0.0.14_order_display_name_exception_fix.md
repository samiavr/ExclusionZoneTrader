# 作業ログ: 発注時アイテム名解決のJava例外（IllegalArgumentException）完全修復 (v1.0.0.14)

**日付**: 2026-09-29  
**対象コンポーネント**: `RadioTrader_ClientBridge.lua`, `RadioTrader_UI.lua`, `RadioTraderMod`, `RadioTraderMod_B42`, `mod`  

---

## 1. 発生していた問題

ユーザーがUI上でアイテム（例: `RadioTrader_Crate_Food`）を選択して「発注する」をクリックした際、赤いエラー通知ボックスが表示された。

ゲームログ `console.txt` の精査結果：
```
ERROR: General f:538> Lua((MOD:Radio Trader Mod)).getItemDisplayName> Exception thrown
java.lang.IllegalArgumentException: fullType must contain "." i.e. module.type at Translator.getItemNameFromFullType(Translator.java:603).
Stack trace:
	zombie.core.Translator.getItemNameFromFullType(Translator.java:603)
	zombie.Lua.LuaManager$GlobalObject.getItemNameFromFullType(LuaManager.java:7322)
	Lua((MOD:Radio Trader Mod)).getItemDisplayName(RadioTrader_ClientBridge.lua:58)

	Lua((MOD:Radio Trader Mod)).onClientCommand(RadioTrader_ServerEngine.lua:377)
```

---

## 2. 原因の調査と特定

1. **バニラAPI `Translator.getItemNameFromFullType` の前提条件**:
   - Project Zomboid の Java メソッド `getItemNameFromFullType(fullType)` は、`fullType` 文字列内にモジュール区切りのドット（`.`、例: `Base.Axe`）が含まれていることを強制するバリデーションがある。
   - 含まれていない場合、`IllegalArgumentException: fullType must contain "."` をスローする仕様。

2. **短縮カスタムIDの引き渡し**:
   - クレートアイテムなどのカスタムアイテムIDは `RadioTrader_Crate_Food` であり、ドット（`.`）が含まれていない。
   - `RadioTrader_ClientBridge.lua` の `getItemDisplayName` では、ドットの有無を検証せず、さらに `pcall` などの例外保護なしで `getItemNameFromFullType` を直接呼び出していたため、Java例外がキャッチされずクラッシュ/赤エラーとなった。
   - また、`RadioTrader_ClientBridge.lua` では `UI.json` に定義済みのカスタムクレート翻訳キー（`UI_RadioTrader_Item_RadioTrader_Crate_Food` 等）の事前チェックが漏れていた。

---

## 3. 実施した修正

1. **`RadioTrader_ClientBridge.lua` の `getItemDisplayName` 刷新**:
   - `UI_RadioTrader_Item_<fullType>` の翻訳キーを最優先で照会（「食料補給ダッフルバッグ (詰合わせ)」等の日本語名を即時取得）。
   - ドット（`.`）が含まれている場合（`string.find(..., "%.")`）のみ、かつ `pcall` で安全に保護して `getItemNameFromFullType` を実行。
   - `ScriptManager` および `getItem` によるスクリプト照会も `pcall` 安全ラッパーで保護。

2. **`RadioTrader_UI.lua` の `getItemDisplayName` 防御強化**:
   - 同様に `string.find(..., "%.")` チェックと `pcall` ラッパーを適用し、未定義アイテムIDが渡された際のリスクを根絶。

3. **全環境同期 & 静的検証**:
   - `tmp/sync_dirs.py` を実行し、`RadioTraderMod` から `RadioTraderMod_B42` および `mod` へ完全同期。
   - `scripts/check_mod_health.py` による全21ファイルの静的解析を実施（Critical Errors: 0, I18N Warnings: 0, ALL PASS）。

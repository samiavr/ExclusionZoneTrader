# 作業ログ: 大規模ホード化（Mega Horde）システム＆緊迫無線メッセージ分岐の実装

- **日付**: 2026-10-01
- **バージョン**: v1.0.0.33
- **対象機能**: 低確率での大規模ホード（Mega Horde）発生機能、サンドボックス設定追加、ヘリ接近時・投下時緊迫無線メッセージ分岐

---

## 1. 概要と背景
物資投下イベントの緊張感を劇的に高めるため、物資投下ヘリ飛来時に低確率（デフォルト 15%）で通常の2.5倍規模のゾンビホードが発生する「大規模ホード（Mega Horde）」機能を実装。
これに伴い、ヘリ接近時（到着10分前）および投下完了時のパイロット無線通信・UIログの文言が緊迫感あふれる警告メッセージへと自動分岐する演出を追加した。

---

## 2. 変更・実装内容

### 2.1 コンフィグとサンドボックス設定 (`RadioTrader_Config.lua`, `sandbox-options.txt`, `Sandbox.json`)
* **コンフィグ追加**:
  - `MEGA_HORDE_ENABLED = true`
  - `MEGA_HORDE_CHANCE = 0.15` (15%)
  - `MEGA_HORDE_MULTIPLIER = 2.5` (ゾンビ数2.5倍)
  - `RadioTrader_Config.getMegaHordeChance()` ゲッター実装。
* **サンドボックスオプション追加 (`option MegaHordeChance`)**:
  - `1: なし (0%)`
  - `2: 低い (5%)`
  - `3: 標準 (15%)` [デフォルト]
  - `4: 高い (25%)`
  - `5: 毎回発生 (100%)`
* 日英のサンドボックス翻訳ファイルに設定項目およびツールチップを追加。

### 2.2 サーバー側判定と永続化 (`RadioTrader_DeliveryTimer.lua`, `RadioTrader_ServerEngine.lua`, `RadioTrader_HeliEvent.lua`)
* **発注時判定の整合性確保**:
  - 発注時（`RadioTrader_DeliveryTimer.start`）に `getMegaHordeChance()` を基に乱数抽選を行い、`data.isMegaHorde` をModDataに永続化。
  - 到着10分前の接近警告 `CMD_HELI_APPROACH` 送信時に `isMegaHorde` フラグをペイロードに付与。
  - 投下要請時、`order.isMegaHorde` を `RadioTrader_HeliEvent.trigger(player, isMegaHorde)` に渡してホード規模を2.5倍へ増幅。
  - 大規模ホード発生時は音響誘引波（`fireAcousticWave`）の半径を通常の 400タイルから **600タイル（1.5倍）** へ拡張し、広域のゾンビを一斉に引き寄せる。
  - 配達完了通知 `CMD_DELIVERY_DONE` にも `isMegaHorde` を付与してクライアントへ送信。

### 2.3 クライアント通信演出とUIログ分岐 (`RadioTrader_ClientBridge.lua`, `RadioTrader_UI.lua`, `UI.json`)
* **ヘリ接近時（到着10分前）**:
  - 通常時:
    - 無線: 「投下ポイント接近中。%s 分後に到着する。周囲の熱源多数--警戒を怠るな。」
    - UIログ: 「[!] 投下ポイント接近中。周囲の熱源多数--」（黄色警告）
  - 大規模ホード時:
    - 無線: 「投下地点へ接近中。到着まであと%s分。……おい待て、何だこの数は！？ 奴らが異常な密度で集結しているぞ！ 気をつけろ！」
    - UIログ: 「[!] 警告：異常な規模のゾンビの群れが投下地点へ集結中！」（赤色DANGER）
* **投下完了時**:
  - 通常時:
    - 無線: 「物資投下完了。%s x%s をランディングゾーンに確認せよ。離脱する。」
    - UIログ: 「物資投下完了。%s x%s を LZ に確認せよ。」（緑色通常）
  - 大規模ホード時（通常投下）:
    - 無線: 「投下完了！ 街中の奴らが集まってきてるぞ！ %s x%s を回収して今すぐそこから離脱しろ！ 離脱する！」
    - UIログ: 「[!] 投下完了！ 巨大ホード発生中！ %s x%s を回収して速やかに退避せよ！」（赤色DANGER）
  - 大規模ホード時（おまけ同封）:
    - 無線: 「投下完了（%s x%s）！ 「おまけ（+ %s）も付けたが、生きて帰れよ！」 奴らに囲まれるぞ、急げ！ 離脱する！」
    - UIログ: 「[!] 投下完了！（おまけ: %s） 巨大ホード発生中！ 物資を回収して速やかに退避せよ！」（赤色DANGER）

### 2.4 バグ修正: 配達完了時（deliverItems）の nil オペランド結合エラー修正
* **原因**:
  - 一括発注（カート機能）導入に伴い、`processTrade` で `order.count` が ModData（`KEY_ORDER`）に保存されていなかった。
  - ヘリがLZに到達して `RadioTrader_ServerEngine.deliverItems` が呼ばれた際、ログ出力 `order.itemName .. " x" .. order.count` において `order.count` が `nil` となり、Kahlua の `__concat not defined for operands: null and ...` 例外がスローされていた。
* **修正**:
  1. `RadioTrader_ServerEngine.processTrade`: `totalItemCount` を集計し、`order.count` を確実に保持。
  2. `RadioTrader_ServerEngine.deliverItems`: `order.count` のフォールバック計算と `tostring` による完全安全なログフォーマットに改修。
  3. `RadioTrader_ClientBridge.lua` & `RadioTrader_UI.lua`: アイテム名に既に数量（`" x4"` など）が含まれている場合に `x4 x4` のように二重表示されないよう `itemDisplay` 整形ロジックを導入し、翻訳キーも整然と整理。

### 2.5 バグ修正: 配達完了後のタイマーステート残留（DELIVERINGスタック）自己治癒ロジックの実装
* **原因**:
  - 先の `deliverItems` 例外発生により、直後の `RadioTrader_DeliveryTimer.reset(player)` がスキップされたため、ModData 上で `data.state = DELIVERING` のまま残留していた。
  - そのためUIを開いた際にサーバーから `state=DELIVERING`（配達中）が返され、発注ボタンが無効化（`canOrder = false`）されたままになっていた。
* **修正**:
  1. `RadioTrader_DeliveryTimer.getState`: 注文データ（`KEY_ORDER`）が存在しないのに `state == STATE_DELIVERING` となっているオーファン状態を検知した際、自動的に `reset(player)` を実行して `STATE_COMPLETED` へ自己復旧させるセルフヒーリングを実装。
  2. `RadioTrader_HeliEvent.lua`: 配達処理（`deliverItems`）を `pcall` で保護し、例外が発生しても `DeliveryTimer.reset(player)` が確実に実行されるよう保証。
  3. `RadioTrader_ServerEngine.deliverItems`: 万一未処理の `order` が存在しない状態で呼ばれた場合にも自動でタイマーをリセットするガードを追加。

### 2.6 スポーンゾンビ誘引改善＆デバッグメニューへのメガホードテスト追加
* **ヘリスポーン座標の確認**:
  - ヘリ接近時、ゾンビは「ヘリの現在地」ではなく**「LZ（投下地点・プレイヤー）を中心とした半径35〜200タイルの外周部（森林・建物の死角）」**に段階的にスポーンする設計。
* **ゾンビ分散問題の解消**:
  1. **離脱ヘリの騒音カット**: ヘリ離脱時（`STATE_LEAVING`）のメタ音響（200タイル）を無効化し、スポーンしたゾンビが飛び去るヘリに釣られてLZから離脱するのを防止。
  2. **LZ地点での持続的音響波**: ヘリ到着時および投下後もしばらくの間（約20秒間）、LZ地点から断続的に強力な音響波（400〜600タイル）を複数回放つことで、外周で湧いたゾンビを時限爆弾のように一斉にLZへ向かって突進・集中させるように強化。
* **デバッグメニュー拡張 (`RadioTrader_Debug.lua`, `RadioTrader_DebugServer.lua`)**:
  - `[Heli] Force Heli Event (MEGA HORDE 2.5x)`: 15%の確率を待たずにメガホード版ヘリイベントを即座に強制発動可能。
  - `-> APPROACHING (MEGA HORDE)`: メガホード警告（赤色UIログ＆緊迫無線）を即座にテスト可能。

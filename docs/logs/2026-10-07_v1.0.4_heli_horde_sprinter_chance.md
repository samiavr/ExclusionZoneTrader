# 開発作業ログ: v1.0.4 ヘリホード走るゾンビ（スプリンター）混入確率システムの実装

* **作業日**: 2026-10-07
* **対象バージョン**: v1.0.4
* **対象モジュール**: `RadioTraderMod` (Build 42)

---

## 1. 開発の背景と目的
Project Zomboid バニラの最高難易度（黙示録 / Apocalypse）であっても、ゾンビ速度は「ファストシャンブラー（早歩き）」であり、標準プリセットでは走るゾンビ（スプリンター）は出現しない。
「普段の探索は落ち着いて遊べる歩きゾンビ環境のままで、**物資投下ヘリが呼び寄せるホードの時だけスリリングに走るゾンビが急襲してくる**」というゲーム体験を可能にするため、サンドボックス設定可能なスプリンター混入確率システムを設計・実装した。

---

## 2. 実施内容

### ① サンドボックス設定項目と多言語化の追加
* **ファイル**:
  - `media/sandbox-options.txt`: `option HeliHordeSprinterChance`（enum 5段階: 0%, 5%, 10%, 20%, 50%）を定義。
  - `media/lua/shared/Translate/JP/Sandbox.json`: 日本語翻訳および説明ツールチップを追加。
  - `media/lua/shared/Translate/EN/Sandbox.json`: 英語翻訳および説明ツールチップを追加。

### ② コンフィグ層（`RadioTrader_Config.lua`）の拡張
* `DEFAULTS.HORDE_SPRINTER_CHANCE = 0.0` を追加。
* `RadioTrader_Config.getHordeSprinterChance()` ゲッターを実装（多層フォールバック解決対応）。
* 初期化ログ出力に `SprinterChance=%.0f%%` を追加。

### ③ スポーンキュー（`RadioTrader_ZombieSpawnQueue.lua`）のスプリンター化対応
* `makeSprinter(zObj)` ヘルパー関数を実装:
  - Java API `zObj:changeSpeed(1)` (1 = Sprinter) を安全に呼び出し。
  - `zObj:getModData().bRadioTraderSprinter = true` を付与。
* `spawnZombiesBatch(cell, sq, lzX, lzY, lzZ, batch, isSprinter)`:
  - スプリンター指定時は Java の `createHordeFromTo`（バニラ伝承速度で実体化される）をバイパスし、`addZombiesInOutfit` で直接実体生成して確実に `changeSpeed(1)` を適用。
  - スプリンター指定でない場合も、`Config.getHordeSprinterChance()` の確率ロールで当選した個体をスプリンター化。
* `RadioTrader_ZombieSpawnQueue.enqueue` に `isSprinter` 引数を追加し、スプリンター専用キューを安全に分離管理。

### ④ ヘリイベント（`RadioTrader_HeliEvent.lua`）での先行急襲ディスパッチ
* `trigger` 時にホード総数と確率から `sprinterQuota`（スプリンター枠）を算出（確率ONかつ5体以上の場合は最低1体保証）。
* `updateVirtualHelis`:
  - ヘリが中距離（150〜100タイル）に到達した際、スプリンター枠は遠隔仮想ホード（Popman）を介さず、進行回廊上の視界外（65〜100タイル）へ実体キュー（`isSprinter = true`）として直接先行投入。
  - スプリンター部隊が先行して猛ダッシュでLZへ突撃し、その後ろから通常のシャンブラー大群がゆっくり進軍する「二段構えウェーブ」を実現。
  - 投入したスプリンター頭数は `dispatchedVirtual` に即座に加算され、全体のホード総数が増加しすぎないよう二重湧きを防止。

### ⑤ デバッグサーバー（`RadioTrader_DebugServer.lua`）およびUIシミュレータの連携
* デバッグホード生成テスト時にも `getHordeSprinterChance()` を参照し、スプリンター枠を実体スポーン側へ優先配分して `changeSpeed(1)` を適用。
* `test_ui.html` のパラメータ表に `HORDE_SPRINTER_CHANCE` を追加。

## 3. 動作仕様一覧

| サンドボックス選択肢 | 混入率 | 挙動概要 |
|---|---|---|
| **1: なし (0%)**【デフォルト】 | 0% | 従来通り、ワールドの通常ゾンビ速度（シャンブラー等）のみ。 |
| **2: 微量 (5%)** | 5% | 20体に1体の割合で突撃。中規模ホード（20体）で約1体。 |
| **3: スリル (10%)** | 10% | 10体に1体の割合で突撃。中規模ホードで2〜3体。 |
| **4: 凶悪 (20%)** | 20% | 5体に1体の割合で突撃。小隊規模で走ってくる。 |
| **5: 悪夢 (50%)** | 50% | 半数が猛ダッシュ。拠点のトラップ・火力が試される高難度戦。 |

---

## 4. 影響範囲と整合性
* 既存の遠隔仮想ホード100%（Popman）設定、ステルスドローン配送、大規模ホード（MegaHorde）機能への干渉・破壊なし。
* ドローン配送時（`isDrone = true`）はホード自体がゼロになるため、スプリンターも湧きません。

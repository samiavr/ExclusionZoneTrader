# 開発作業ログ: v1.0.7 スカベンジャー募集チラシによる交易周波数アンロックシステムの実装

* **作業日**: 2026-10-07
* **対象バージョン**: v1.0.7
* **対象モジュール**: `RadioTraderMod` (Build 42)

---

## 1. 開発の背景と目的
従来の実装では、ゲーム開始直後であっても無線機を 104.8 MHz に合わせれば即座に取引メニューが表示される仕様であった。
しかし、プレイヤーにとっては「なぜこの周波数なのか」「誰が何の目的で取引しているのか」という世界観上の文脈が希薄であり、メタ知識として周波数を直接指定する不自然さがあった。
そこで、世界観への没入感を高めるプログレッション要素として、**「外の世界の民間ネットワークが散布したスカベンジャー募集チラシ（手書きメモ）を読み、周波数（104.8 MHz）を手帳に記録して初めて交易メニューが解放される」**システムを設計・実装した。

---

## 2. 実施内容

### ① チラシアイテムの生成と本文テキスト
* **ファイル**: `RadioTrader_UnlockFlyer.lua`
* バニラの手書き紙アイテム（`Base.SheetPaper2`）をベースに、プレイヤーによる改ざんを防止した公式チラシを動的生成：
  - `item:setName("スカベンジャー募集！")`
  - `item:setCustomName(true)`
  - `item:setLockedBy("ExclusionZoneTrader")`
  - `item:setCanBeWrite(false)`
  - `modData.bRadioTraderFlyer = true`
* **本文テキスト**:
  ```text
  生き残っている生存者へ。
  我々はノックス隔離地域の外側で活動する民間ネットワークだ。
  隔離地区の資料保存と物資を求めている。
  報酬は他の生存者が手に入れた物資だ。
  取引を希望する者は、無線機の周波数を【 104.8 MHz 】に合わせろ。
  空から物資を投下してやる。幸運を。
  ```

### ② 入手ルート（未読時限定）
* **ゾンビ討伐ドロップ**:
  - `Events.OnZombieDead` で未アンロック時に **4%** の確率でゾンビのインベントリにチラシを追加。
* **採集 (Foraging)**:
  - `ISForageAction:perform` をフックし、未アンロック時に **5%** の確率で追加発見。
* **重複ドロップ停止**:
  - プレイヤーが一度読了してアンロック（`md.bRadioTraderUnlocked = true`）した後は、ゾンビドロップおよび採集からの排出を完全停止し、不要なチラシによるインベントリ圧迫を防止。

### ③ 読了演出と手帳記録
* `ISReadABook:perform` および `Events.OnReadLiterature` の二重網でチラシ読了を確実に検知。
* 読了時の演出：
  - 頭上グリーン通知: `交易周波数 (104.8 MHz) を手帳に記録した！` (HaloText) のみシンプルに表示（独白吹き出しや効果音は鳴らさず静かに記録）。

### ④ UIガード（未アンロック時の完全非表示）
* **ファイル**: `RadioTrader_ContextMenu.lua`
* `onFillWorldObjectContextMenu` の先頭でアンロック状態を判定。
* チラシ未読時は無線機を右クリックしても取引メニューを一切表示せず、周波数のネタバレを完全に防ぐ。

### ⑤ サンドボックス設定の配備
* **設定キー**: `RequireFlyerToUnlock` (Boolean, デフォルト: true)
* `media/sandbox-options.txt`, `RadioTrader_Config.lua`, および日英翻訳ファイル（`Sandbox.json`）に対応。
* OFF に設定することで、従来通り最初から周波数さえ合わせれば即座に取引可能な設定も可能。

# 2026-10-13 銃器・弾薬・マガジン買取査定機能（耐久度9割判定＆ループ防止設計）

## 概要
サバイバーが探索で入手した余剰の銃器・弾薬箱・マガジン・アタッチメントの売却・買取に対応しました。
武器バッグ（Arms & Ammo Duffel Bag: 1000 CR）を購入・解体して売却することで利益が出る「無限増殖ループ」を完全に防止するため、買取価格を安全な水準（回収率 10〜25%）に抑制しています。

## 買取仕様・価格設計
1. **銃器本体 (`Firearm`)**:
   - **ハンドガン・リボルバー**: ベース **25 CR**
   - **大型銃器（ライフル・ショットガン）**: ベース **45 CR**
   - **耐久度（Condition）判定**:
     - **耐久度 90% 以上（美品）**: 満額（1.0倍） / 表示: `[美品] <銃器名>`
     - **耐久度 90% 未満（消耗）**: 半額（0.5倍） / 表示: `[使用感あり] <銃器名>`
2. **弾薬箱 (`AmmoBox`)**:
   - 未開封の弾薬箱（9mm, .45, .44, .38, Shotgun, .223, .308, 5.56等）: **18 CR**
3. **マガジン・弾倉 (`Magazine`)**:
   - 各種マガジン: **8 CR**
4. **銃器アタッチメント (`GunPart`)**:
   - スコープ、チョーク、スリング、レーザーサイト、反動パッド等: **12 CR**
5. **バラ弾（Loose Bullets）**:
   - **買取対象外（完全除外）**

  - `RadioTrader_AssessContainer` に Java クラスフォールバック（`HandWeapon` かつ `isRanged`, `WeaponPart`）を追加。

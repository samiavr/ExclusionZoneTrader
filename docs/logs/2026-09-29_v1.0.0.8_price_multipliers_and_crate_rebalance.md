# 作業ログ: 2026-09-29 v1.0.0.8 取引価格倍率設定＆物資ダッフルバッグ価格高額化

## 1. 概要
- **ユーザー要望**: 「もっと購入は高額で良い気がするので、設定で金額倍率変えれると良いな」
- **対応内容**:
  1. サンドボックス設定 (`sandbox-options.txt`) に購入倍率 `BuyPriceMultiplier` および売却倍率 `SellPriceMultiplier` を追加。
  2. 多言語ファイル (`Translate/JP/Sandbox.json`, `Translate/EN/Sandbox.json`) を整備し、設定画面で日本語・英語での名称とツールチップ表示をサポート。
  3. `RadioTrader_Config.lua` に倍率ゲッター関数を実装し、サンドボックス設定値を安全にロード。
  4. `RadioTrader_ItemsTable.lua` にて物資クレート（ダッフルバッグ）のベース価格をサバイバル相場に合わせて再調整。実効購入価格ヘルパー `RadioTrader_ItemsTable_GetEffectiveBuyPrice(basePrice)` を新設。
  5. UI側 (`RadioTrader_UI.lua`) で実効価格を一覧表示・アイテム詳細・注文メッセージへ反映。
  6. サーバー側 (`RadioTrader_ServerEngine.lua`) の `processTrade`（購入引き落とし）および `assessContainer`（売却査定）に各倍率を適用。

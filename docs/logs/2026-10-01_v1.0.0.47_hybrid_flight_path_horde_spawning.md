# 作業ログ: 2026-10-01 (v1.0.0.47) - ヘリ飛行ルート連動・追従ハイブリッドホードスポーンの実装

## 1. 概要
- **ユーザーフィードバック**:
  - 「音が聞こえ始める範囲に入ったタイミングでヘリ周辺にゾンビを段階スポーンってなくなったっけ」
  - 「近接スポーンがヘリ側に向くようになってない気がする」
- **課題と原因分析**:
  - 音が聞こえ始める200タイル〜50タイルでの4段階分割スポーンロジックは存在していたが、呼び出し先が `lzX, lzY`（LZ/拠点）基準固定だったため、ヘリが遠くにいる時点から拠点のすぐ近くに湧いてしまっていた。
  - スポーン角度のコーン拡散が `+/- 60度`（合計120度）と広角すぎたため、ヘリ進入方向だけでなく拠点の側面（横）からも湧いて挟み撃ちのように見えていた。
  - 遠隔仮想ホード（Popman）もLZから135タイル地点に固定発注されており、ヘリのリアルタイム飛行位置から発進していなかった。

## 2. 実施内容

### 2.1 遠隔ホードのヘリ現在地追従発進 (プランA)
- `RadioTrader_HeliEvent.lua`:
  - ヘリが 200, 150, 100 タイル先を飛行しているタイミングで、**その瞬間のヘリ現在地（`heli.x, heli.y`）** を起点として `ZombiePopulationManager:createHordeFromTo` を発進。
  - ヘリが通過した遥か遠くの未ロード空間から、ヘリの飛行航跡を追いかける大群をリアルタイム生成。

### 2.2 近接スポーンの飛行ルート直線連動 ＆ コーン鋭角化 (プランB)
- `RadioTrader_ZombieSpawnQueue.lua` & `RadioTrader_HeliEvent.lua`:
  - コーン拡散角度を `+/-60度` -> **`+/-30度`（合計60度のシャープな進入回廊）** に絞り込み。横からのスポーンを排除し、ヘリが飛んできた空の真下のラインから一直線に突撃するよう修正。
  - ヘリ接近距離 `newDist` に応じてスポーン探索半径を連動：
    - `newDist >= 150`（ヘリ遠方）: LZから **85〜120 タイル**（ロード外縁・ヘリ足元）
    - `newDist < 150`（ヘリ接近）: LZから **50〜85 タイル**（中距離）
  - プレイヤー45タイル絶対セーフティ（`PLAYER_SAFETY_RADIUS_TILES = 45`）は常時維持。

## 1. 概要と背景

前バージョン（v1.0.0.50）までのヘリコプター飛来・サーチライト演出・Popman遠隔仮想ホード連携に続き、MODのコア経済システムとゲーム体験を劇的に洗練させるための大型アップデートを実施した。
不用品の換金と発注をシームレスにつなぐ「下取り相殺システム」、乾電池箱や布束などの重要資材を安定供給する「超プレミアム固定枠プール」、バニラアイテムの出現ウェイトに基づいた「希少度価格一本化」、そしてGitHub公開に向けたドキュメントとリポジトリ構造の最適化を完了した。

## 2. 主な実装・変更内容

### 2.1 下取り相殺システム (Trade-in Offset) と差し入れ演出
- **自動相殺ロジック (`RadioTrader_ServerEngine.lua`)**:
  - 発注処理時に、登録済みドロップボックス内の換金対象アイテム（現金・貴金属・車両パーツ・家具・軍用品等）を一括回収し、購入費用と相殺。
  - 所持CRが不足していても、ドロップボックスの査定額で補填可能に。
  - UI上で `所持CR + ドロップボックス査定額 = 合計利用可能予算` をリアルタイム表示。
- **不用品回収フライト**:
  - 物資を購入せず不用品の回収のみを依頼するフライト（運送費 100 CR）を追加。
  - 依頼時、低確率で現場クルーからの「幻の焼きたてスイーツ」がドロップボックスに差し入れられるフレーバー演出を実装。
- **現場クルー特製ランチボックス**:
  - ドロップボックス査定額が 5,000 CR 以上（大型家具や軍需物資の下取り）の場合、現場クルーからの感謝の差し入れとして特製ランチボックスを同封。

### 2.2 超プレミアム固定枠テーブルの新設 (`RadioTrader_DailyPremiumPool`)
- **アイテム選定と実在IDの確認**:
  - バニラスクリプト（`media/scripts`）を実測調査し、正式なIDを登録：
    - 布束（綿・デニム）、麻布・毛糸
    - 鞣し革（大: `Base.Leather_Crude_Large_Tan` 4,000 CR / 中: `Base.Leather_Crude_Medium_Tan` 2,500 CR / 小: `Base.Leather_Crude_Small_Tan` 1,000 CR）
    - 箱入り釘・箱入りネジ・乾電池BOX
    - 建材袋（セメント袋、土嚢袋、砂利袋、粘土袋）
    - 動物飼料、野菜の種袋
- **シャッフルプール統合**:
  - バニラ9大カテゴリコンテナと同列に `{ category = "Premium", label = "Premium", isPremium = true }` として登録し、全6枠の日替わり枠にランダム混入。

### 2.3 バニラ日替わり品の希少度（出現ウェイト）一本化
- **品名ハードコード判定の撤廃**:
  - 従来のアイテム名検索による例外ハードコードを完全撤廃。
  - バニラの出現ウェイトのみで4段階（激レア: `<=0.1` 4,000 CR / レア: `<=1.0` 2,100 CR / アンコモン: `<=10.0` 1,200 CR / コモン: `>10.0` 250 CR）に判定を一本化。
  - ユーザー考案の価格計算式: `( (基準単価 + 乱数(1〜10)*10) * 個数 * 乱数(1.00〜2.00) ) * BuyPriceMultiplier` を適用。

### 2.4 UIリロール処理の安全化 (`RadioTrader_UI.lua`)
- 所持CR不足でリロールを試みた際に `playSound`（未定義）が呼ばれてクラッシュしていた不具合を修正。
- 音声呼び出し依存を排除し、UIログへの赤文字警告表示のみに整理。

### 2.5 GitHub公開・リポジトリ最適化
- **ドキュメントの洗練 (`README.md`, `spec_radio_trader.md`)**:
  - 仕様書（`spec_radio_trader.md`）に下取り相殺・超プレミアム固定枠・相場変動式を完全記録。
  - `README.md` は内部確率や詳細数値を控え、サバイバルゲームのフレーバーと分かりやすさを重視した表現に調整。
- **ローカルスクリプトのGit除外**:
  - 一時的な調査・テスト用スクリプトを削除。
  - `scripts/` ディレクトリ自体を `.gitignore` に追加し、ローカル検証ツール（`check_mod_health.py`, `build_release_zip.py`）をディスク上に保持したまま、GitHubの公開ツリーから完全に除外。

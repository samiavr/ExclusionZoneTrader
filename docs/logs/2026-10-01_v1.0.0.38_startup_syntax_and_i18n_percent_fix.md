# 2026-10-01 v1.0.0.38 起動時構文エラーと翻訳パーセント記号例外の修正

## 1. 概要
- ゲーム起動時に発生していた赤エラー（例外）を `console.txt` から特定し、以下の2つの根本原因を解消。
  1. `RadioTrader_DebugServer.lua` での `if isMega then` ブロックの `end` 抜けによる Kahlua 構文エラー（KahluaException: 'end' expected）。
  2. `Translate/JP/Sandbox.json` および `Translate/EN/Sandbox.json` 内の大規模ホード選択肢で、裸の `%` 記号（例: `0%`）が Java の `String.format` / Formatter によって未知のフォーマット指定子（`UnknownFormatConversionException: Conversion = ')'`）と誤認されていた問題。

## 2. 修正詳細
1. **[Server] [RadioTrader_DebugServer.lua](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/server/RadioTrader_DebugServer.lua)**:
   - `cmdForceZombieSpawn` 関数内の `if isMega then` に閉じキーワード `end` を追記。
   - 重複していたコメントヘッダーを整理。

2. **[Shared] [Translate/JP/Sandbox.json](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/shared/Translate/JP/Sandbox.json) & [Translate/EN/Sandbox.json](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/shared/Translate/EN/Sandbox.json)**:
   - Java Formatter の仕様（PZ B42 のバニラ仕様に準拠）に従い、選択肢内の `%` を `%%`（エスケープ済みパーセント）に修正:
     - `0%` ➔ `0%%`
     - `5%` ➔ `5%%`
     - `15%` ➔ `15%%`
     - `25%` ➔ `25%%`
     - `100%` ➔ `100%%`

3. **[Tooling] [check_mod_health.py](file:///d:/VSCODE/project/zomboid/radio_trading_mod/scripts/check_mod_health.py)**:
   - 翻訳 JSON 内に裸の未エスケープ `%` が含まれている場合に警告・エラーを出力する自動検査ロジックを新規追加。再発防止を自動化。

# 2026-10-01 v1.0.0.37 配達ヘリホバリング時のLZサーチライト照射演出

## 1. 概要
- 配達ヘリが LZ（荷物投下地点）に到着して物資投下・ホバリング（滞空約20分ゲーム内＝約50秒間）している間、上空から地上を照らす高輝度サーチライト演出（`IsoLightSource`）を点灯させ、ホバリング終了（離脱開始）と同時に消灯する機能を実装。
- 夜間や夕暮れの視認性向上とともに、支援ヘリが上空から直下を強烈に照らし出す映画さながらの臨場感・没入感を実現。

## 2. 実装詳細
1. **[Shared] [RadioTrader_Config.lua](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/shared/RadioTrader_Config.lua)**:
   - コマンド定数を追加:
     - `RadioTrader_Config.CMD_HELI_HOVER_START = "heliHoverStart"`
     - `RadioTrader_Config.CMD_HELI_HOVER_END   = "heliHoverEnd"`

2. **[Server] [RadioTrader_ServerEngine.lua](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/server/RadioTrader_ServerEngine.lua)**:
   - マルチプレイ・シングルプレイ双方に対応した一斉通知ヘルパー `RadioTrader_ServerEngine.broadcastToClients(cmd, args)` を追加。

3. **[Server] [RadioTrader_HeliEvent.lua](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/server/RadioTrader_HeliEvent.lua)**:
   - ヘリが LZ に到着して `STATE_HOVERING` へ移行した瞬間、LZ 座標 (x, y, z) と照射半径 (20) を含む `CMD_HELI_HOVER_START` を全クライアントへブロードキャスト。
   - ホバリング時間（`HOVER_DURATION`）経過して `STATE_LEAVING` へ移行した瞬間、およびヘリデスポーン時に `CMD_HELI_HOVER_END` をブロードキャスト。

4. **[Client] [RadioTrader_ClientBridge.lua](file:///d:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/client/RadioTrader_ClientBridge.lua)**:
   - `IsoLightSource.new(x, y, z, 0.95, 0.98, 1.0, 20)` による青白色高輝度光源の生成と `getCell():addLamppost(light)` による点灯。
   - `CMD_HELI_HOVER_END` 受信時の `getCell():removeLamppost(light)` による消灯・参照破棄。
   - フェイルセーフとして、90秒タイマーによる自動消灯監視（`Events.OnTick`）およびプレイヤー死亡時（`Events.OnPlayerDeath`）の消灯フックを配備。光源がワールド上に残留する問題を完全に防止。

5. **[Docs] [spec_radio_trader.md](file:///d:/VSCODE/project/zomboid/radio_trading_mod/docs/spec_radio_trader.md)**:
   - セクション 6.8 にサーチライト照射演出の仕様を追記。

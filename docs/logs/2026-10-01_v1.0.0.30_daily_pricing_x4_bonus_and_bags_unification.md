## 1. 目的と概要
ユーザーフィードバックに基づき、以下のUI表示・価格バランス・ゲーム体験の改善を実施：
1. **日替わり特売の表示形式変更**: `アイテム名 x 数量  -  価格 CR` （例: `麻袋(粘土) x 4  -  800 CR`）への統一。
2. **日替わり品ベース価格の4倍引き上げ**: ランダム補給バッグとの相対的価値バランスを考慮し、コモン資材・レア品・激レア品の価格を4倍ベースへ改定。
3. **おまけ同封機能の実装**: 日替わり品発注時、購入品に加えてランダムCrateテーブルから「おまけアイテム (+1個)」をコンテナに同封し、「おまけしといたぜ！」の無線メッセージとUIログを表示。
4. **種類別バッグタブの集約**: 左ペインの13個の個別ダッフルバッグタブを「[補給] 種類別バッグ (`Bags`)」に一本化し、中央リストに全種並べて選択するUIへ刷新。タブボタンを押しやすい高さ（32px）に最適化。
5. **ModDataキャッシュ自動刷新 (`DAILY_DATA_VERSION = 2`)**: 既存セーブデータで旧価格（400 CR等）が残らないよう、バージョンチェックによる即時自動更新を導入。

## 2. 変更内容詳細

### 2.1 UI表示形式とカテゴリ別ラベル制御 (`RadioTrader_UI.lua`)
- `loadCategory(categoryKey)`:
  - `Daily` カテゴリ: `("%s x %d  -  %d CR"):format(dispName, entry.count or 1, effPrice)`
  - その他カテゴリ（`Bags`, `Misc`）:
    - `count > 1` の場合: `("%s x %d  -  %d CR"):format(dispName, entry.count, effPrice)`
    - 通常品（1個）: `("%s  -  %d CR"):format(dispName, effPrice)`
- `onItemSelect()`:
  - アイテム詳細パネルの見出しにも `[%s x %d]` を表示し、セット数量が一目でわかるように改善。

### 2.2 日替わり価格4倍改定 ＆ テーブル調整 (`RadioTrader_ItemsTable.lua`)
- `calculateDailyItemPriceAndCount`:
  - 激レア品 (ウェイト <= 0.1): 1個限定, 3200 CR (手斧・金床・貴重本等)
  - レア品 (ウェイト <= 1.0): 1個, 1680 CR (工具・特殊医薬品・鋼板・トーチ等)
  - アンコモン (ウェイト <= 10.0): 1〜2個, 960 CR (缶詰・鎮痛薬・縫い針等)
  - コモン資材 (ウェイト > 10.0):
    - 木板10枚束: 880 CR
    - 粘土麻袋4個 / 砂袋4個 / セメント4個 / 鉄板4個: 800 CR
    - 釘箱2個 / ネジ箱2個 / 肥料2個: 720 CR
    - 布束2個 / 革材2個: 720 CR
    - 糸4個 / 毛糸4個: 560 CR
    - その他コモン資材3個: 640 CR
  - 特殊高額品: 発電機 3600 CR / アリスパック 3000 CR

### 2.3 サーバーサイドおまけ同封 ＆ キャッシュ自動更新 (`RadioTrader_ServerEngine.lua`)
- `DAILY_DATA_VERSION = 2` を定義。`dailyState.version ~= DAILY_DATA_VERSION` の場合、日付変更を待たずに即座に4倍価格の新データで再抽選・更新。
- `deliverItems`:
  - 発注品に日替わり品が含まれている場合、全9大ジャンルのバニラCrateテーブルからランダムに1つのアイテム（おまけ）を生成してLZコンテナに同封。
  - `CMD_DELIVERY_DONE` に `bonusItemName` を含めて送信。

### 2.4 クライアント無線演出 ＆ 翻訳完備 (`RadioTrader_ClientBridge.lua`, `Translate/JP/UI.json`)
- 無線通信:
  - `UI_RadioTrader_Radio_DeliveredWithBonus`: `物資投下完了（%s x%s）。「おまけしといたぜ！」（+ %s）。イーグル1帰投する。`
- UIログ:
  - `UI_RadioTrader_Log_DeliveredWithBonus`: `物資投下完了。%s x%s を確認。「おまけしといたぜ！」（+ %s 同封）`
- 3タブ集約:
  - `UI_RadioTrader_Cat_Daily`: `[特売] 日替わり特売`
  - `UI_RadioTrader_Cat_Bags`: `[補給] 種類別バッグ`
  - `UI_RadioTrader_Cat_Misc`: `[物資] 特殊・大型`

## 1. 概要・背景
投下準備完了通知音（`CMD_REQUEST_DROP`）および売却完了音（`sellSuccess`）において、従来はバニラのスキルレベルアップ音（`GainExperienceLevel`）が再生されており、プレイヤーのスキル上昇と誤認しやすい問題があった。
また、世界観（無線通信・サバイバル）に統一感を持たせるため、ヘリの通過音（`Helicopter`）およびエラー・拒否音（`AccessDenied`）を除き、通信・通知・取引系SEをバニラ実在の無線音声 `RadioTalk`（`Object/Radio/Program`）へ統一した。

---

## 2. 実施内容

1. **バニラサウンド仕様の徹底調査**:
   - `sounds_object_radio.txt` および `ZomboidSound.bank` 内の定義を解析。
   - `RadioTalk` は FMOD イベント `Object/Radio/Program`（約1〜2秒の無線人の声）にマッピングされており、`loop = true` がない単発サウンドであることを確認。
   - `player:playSound("RadioTalk")` は Java 内部で `FMODSoundEmitter.playSoundImpl`（ワンショット再生）を呼び出すため、Lua 側でタイマーをかけずとも約1〜2秒で自然に鳴り止む仕様であることを解明。

2. **`RadioTrader_ClientBridge.lua` のSE変更**:
   - **投下準備完了** (`CMD_REQUEST_DROP`): `GainExperienceLevel` → `RadioTalk`
   - **売却成功** (`sellSuccess`): `GainExperienceLevel` → `RadioTalk`
   - **発注受付** (`CMD_TRADE_ACCEPTED`): `RadioStatic` → `RadioTalk`
   - **ヘリ接近警告** (`CMD_HELI_APPROACH`): `RadioStatic` → `RadioTalk`
   - **リロール成功** (`rerollSuccess`): `RadioStatic` → `RadioTalk`
   - **配達完了** (`CMD_DELIVERY_DONE`): `Helicopter`（維持）
   - **エラー / 注文期限切れ** (`error`, `CMD_ORDER_EXPIRED`): `AccessDenied`（維持）

3. **ドキュメント作成・更新**:
   - `docs/sound_candidates.md` に全バニラ候補リスト、カテゴリ別特徴、および今回の統一仕様を恒久ドキュメントとして記録。

# 2026-10-22 v1.1.6: 銃器ダッフルバッグの銃器・マガジン・弾薬ワンセット充填 ＆ 最大1挺マルチスロット補給システム

## 1. 概要
プレイヤーが購入する「銃器ダッフルバッグ（Arms & Ammo Duffel Bag）」において、従来のアイテム完全独立抽選に起因する以下の問題を解消した：
- **課題**: 
  - 銃本体が当選しても対応するマガジンが出ない（手動単発装填しかできない）、マガジンが一切入っていない、または別の銃のマガジンばかりが出る。
  - 1発目で銃が出て即終了してしまうと、バッグのアイテム数が少なく寂しい状態になる。
- **改善仕様**:
  - **規定数（3〜8枠）に達するまでアイテム抽選を最後まで継続**。
  - **銃本体はバッグ1個につき「最大1挺」厳守**（2挺目以降の銃器が抽選された場合は自動スキップ・再抽選して弾薬等の物資に置換）。
  - **銃本体が当選した瞬間に、その銃に対応するマガジン（1個）＋対応バラ弾（5〜20個）をセット同梱**。
  - 銃本体が出なかった場合は、通常通り弾薬箱・バラ弾・予備マガジン・パーツ等の物資が3〜8個分充填されて完了する。

## 2. 実装詳細とアーキテクチャ

### 2.1 銃器スペックマッピングテーブル (`RadioTrader_WeaponSpecs`)
[`RadioTrader_ItemsTable.lua`](file:///D:/VSCODE/project/zomboid/radio_trading_mod/RadioTraderMod/42/media/lua/shared/RadioTrader_ItemsTable.lua#L1560) において、B42バニラの全銃器に対応するマガジンIDおよびバラ弾IDを定義：
- **拳銃 (Handguns)**:
  - `Base.Pistol` (9mm): `Base.9mmClip` / `Base.Bullets9mm`
  - `Base.Pistol2` (.45): `Base.45Clip` / `Base.Bullets45`
  - `Base.Pistol3` (.44): `Base.44Clip` / `Base.Bullets44`
  - `Base.Revolver` / `Revolver_Short` (.38): `mag = nil` / `Base.Bullets38`
  - `Base.Revolver_Long` (.44): `mag = nil` / `Base.Bullets44`
- **ショットガン (Shotguns)**:
  - `Base.Shotgun`, `DoubleBarrelShotgun`, 各種ソウドオフ: `mag = nil` / `Base.ShotgunShells`
- **ライフル・カービン (Rifles & Carbines)**:
  - `Base.AssaultRifle` (M16): `Base.556Clip` / `Base.556Bullets`
  - `Base.AssaultRifle2` (M14): `Base.M14Clip` / `Base.308Bullets`
  - `Base.HuntingRifle` (MSR788): `Base.308Clip` / `Base.308Bullets`
  - `Base.VarmintRifle`: `Base.223Clip` / `Base.223Bullets`
  - `Base.L94_Rifle` (.30-30): `mag = nil` / `Base.3030Bullets`
  - `Base.L92_Carbine` (.357): `mag = nil` / `Base.Bullets357`

### 2.2 銃器バッグ専用充填ハンドラ (`RadioTrader_ItemsTable_FillWeaponsBag`)
- `RadioTrader_Crate_Weapons` の定義に `isWeaponsBag = true` を追加。
- `RadioTrader_ItemsTable_FillDuffelBag` から専用分岐として呼び出し。
- `mainItemsCount < targetCount`（3〜8枠）までループを実行：
  - 銃器当選時：
    - `hasGun == false` の場合：
      1. 銃本体をバッグへ追加し `hasGun = true`。
      2. `spec.mag` が存在する場合、`instanceItem(spec.mag)` でマガジン1個を追加。
      3. `spec.ammo` が存在する場合、`ZombRand(5, 21)` で 5〜20個 のバラ弾を追加。
      4. **ループは終了せず継続**し、残りの枠を他の弾薬・物資で充填。
    - `hasGun == true` の場合：
      - 2挺目以降の銃器のため、バッグに追加せず即座にスキップ（再抽選）。
  - 通常物資当選時：
    - 弾薬箱・予備マガジン・パーツ等をバッグに追加。

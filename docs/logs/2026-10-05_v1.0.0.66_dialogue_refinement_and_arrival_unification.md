# 2026-10-05 v1.0.0.66 無線セリフ・トーン＆マナー統一 ＆ 日英同期 ＆ アイテム名ローカライズ ＆ 到着通知一本化

## 1. 概要
- **目的**:
  1. 無線セリフや右クリックメニュー、UIログのトーン＆マナーを統一し、ヘリ配送・ドローン配送の表現および取引先キャラクターの口調を統一する。
  2. 日本語辞書（`UI.json`, `ContextMenu.json`）の手動調整内容を英語辞書（`EN/UI.json`, `EN/ContextMenu.json`）へ完全同期する。
  3. 発注・配達完了時に英語名や内部ID（`Base.xxx`）がそのまま表示されていた問題を解消し、ゲーム内日本語アイテム名および複数品目表示（「〇〇 (他 N 品)」）に対応する。
  4. カート一括発注時に「不用品回収依頼」が含まれている場合でも、通常物資（食料バッグ等）を優先して代表品名としてアナウンス・ログに表示する。
  5. 10分前の接近警告（APPROACHING）を撤廃し、到着時刻に直接投下準備完了（`READY_FOR_DROP`）へ遷移するようタイマー制御を簡素化・一本化する。
  6. タイマー改修時に混入した構文エラー（パースエラー）を修正し、「ネットワークに接続」時に発生した null 参照例外を完全に解消する。
- **対象バージョン**: v1.0.0.66

## 2. 実施内容

### 2.1 無線セリフ・トーン＆マナーの統一
- **ユーザー指定セリフの反映 (`Translate/JP/UI.json`)**:
  - `UI_RadioTrader_Radio_Assessed`: ドロップボックスの中身を査定したぜ。合計 %s CRだな。
  - `UI_RadioTrader_Radio_LZConfirmed`: 新しいLZの座標を受け取った。
  - `UI_RadioTrader_Say_ReadyForDrop`: おい、近くの上空まで来てるぜ。LZの箱のそばで投下の合図を送ってくれ
  - `UI_RadioTrader_Say_OrderExpired`: 合図がない。燃料切れになる前に帰還する。半分（%s CR）だけ返金だ。
  - `UI_RadioTrader_Err_NOT_ENOUGH_CREDITS`: クレジットが不足しています。
  - `UI_RadioTrader_Err_NOT_READY_FOR_DROP`: 到着圏外だ。待機していてくれ。
  - `UI_RadioTrader_Err_LZ_NOT_SET`: 落とす場所（LZ）を指定してくれ。
  - `UI_RadioTrader_Radio_OrderAcceptedDrone`: 受注完了。%s 静かなやつを手配しておくぜ。コスト: %s CR。
  - `UI_RadioTrader_Radio_ApproachDrone`: LZ上空到達。もう少し待っていてくれ。
  - `UI_RadioTrader_Radio_DeliveredDrone`: 投下完了。またな。
  - `UI_RadioTrader_Radio_FallbackDropNotice`: 指定の箱が塞がっていたか見当たらないため、LZ周辺の地面に投下した。
- **ドローン受注時のプレースホルダー修正 (`RadioTrader_ClientBridge.lua`)**:
  - ドローン受注時に品名とコストが正常に展開されるよう、`itemName` と `cost` を引数として正しくフォーマット。

### 2.3 アイテム名ローカライズ化 ＆ 複数品目フォーマッタ
- **サーバー側データ送信の拡張 (`RadioTrader_ServerEngine.lua`)**:
  - `CMD_TRADE_ACCEPTED` および `CMD_DELIVERY_DONE` において、従来の英語名 `itemName` に加え、`itemId`（モジュールID）および一括注文種別数 `totalKinds` をクライアントへ送信。
- **クライアント側名前解決とフォーマッタ (`RadioTrader_ClientBridge.lua`, `RadioTrader_UI.lua`)**:
  - `getOrderDisplayName(args)` を実装:
    1. `args.itemId` からバニラ翻訳名（`getItemDisplayName(itemId)`）を取得。
    2. もし `itemId` がない場合でも、英語名からIDを逆引き解決する `resolveItemIdFromName(name)` をフォールバックとして配置。
    3. `totalKinds > 1` の場合、`UI_RadioTrader_Order_MultipleSuffix`（`" (他 %d 品)"`）を自動付与してフォーマット。

### 2.4 カート代表アイテム選定の適正化
- **選定優先度ロジック (`RadioTrader_ServerEngine.lua`)**:
  - カート一括発注時（複数品目注文時）に、不用品回収依頼（`RadioTrader_Crate_Pickup`）が含まれていても、他に通常物資（食料、種子、ツール等）が存在する場合は通常物資を優先して `mainItem`（代表アイテム）として選定。
  - これにより、無線やログで「不用品回収依頼 (他 2 品)」ではなく「特製ランチボックス (他 2 品)」のように実質的な発注物資が主役に表示されるよう改善。

### 2.5 接近警告撤廃と到着通知の一本化
- **タイマー制御の簡素化 (`RadioTrader_DeliveryTimer.lua`)**:
  - 10分前の接近警告（`CMD_HELI_APPROACH`）通知を撤廃。
  - `PENDING`（配達待ち）ステートから到着時刻到達時に直接 `READY_FOR_DROP`（合図待ち）へ遷移し、上空到着通知（「おい、近くの上空まで来てるぜ」）のみを送信する一本化フローを構築。
  - `RadioTrader_ClientBridge.lua` に SP/MP 環境でのコマンド二重受信防止用デバウンス（300msガード）を追加。

### 2.6 構文エラー修正と「ネットワークに接続」例外の解消
- **障害原因**:
  - タイマー制御簡素化の編集時に、`RadioTrader_DeliveryTimer.lua:173` 付近の `elseif` の直前に余分な `end` が混入。
  - Kahlua VM が構文エラー（`<eof> expected near end`）でタイマーモジュールの読み込みに失敗し、グローバル変数 `RadioTrader_DeliveryTimer` が nil のままとなった。
  - その結果、「ネットワークに接続」を押した際（`requestState` 受信時）に `RadioTrader_ServerEngine.lua:990` で `RadioTrader_DeliveryTimer.getState(player)` を呼び出して `attempted index: getState of non-table: null` 例外が発生していた。
- **修正**:
  - 余分な `end` を除去し、構文を正常化。

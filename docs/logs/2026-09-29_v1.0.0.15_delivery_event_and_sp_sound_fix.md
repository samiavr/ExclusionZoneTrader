# 作業ログ: 配達イベントクラッシュ（nil呼び出し）およびSP通知・音響イベントの完全修復 (v1.0.0.15)

**日付**: 2026-09-29  
**対象コンポーネント**: `RadioTrader_HeliEvent.lua`, `RadioTrader_DebugServer.lua`, `RadioTrader_ClientBridge.lua`, `RadioTraderMod`, `RadioTraderMod_B42`, `mod`  

---

## 1. 発生していた問題

1. **デバッグメニューから「配達完了（DELIVERING）」を選択すると赤エラー発生**:
   - ゲームログ `console.txt`:
     ```text
     LOG: [RadioTrader][DEBUG] Advancing state to DELIVERING (Instant Drop)...
     LOG: [RadioTrader][HeliEvent] HeliEvent triggered for タリンガブリエル at LZ (6172,5404,0)
     LOG: [RadioTrader][HeliEvent] Acoustic wave fired at (6172,5404,0), radius=400
     ERROR: Lua fail. Message: Object tried to call nil in trigger
        Lua((MOD:Radio Trader Mod)).trigger(RadioTrader_HeliEvent.lua:176)
     ```
   - 176行目のエラーにより、直後の179行目 `RadioTrader_ServerEngine.deliverItems(player)` まで処理が届かず、物資がコンテナに投下されなかった。

2. **「接近警報（APPROACHING）」にしてもヘリの音や無線通知が出ず、ゾンビだけ寄ってきた**:
   - デバッグメニュー `cmdForceState` で `APPROACHING` にした際、`sendServerCommand` を直接呼び出していたため、SP環境（シングルプレイヤー）でクライアントの `OnServerCommand` が発火せず、無線テキストや警告音（SE）が一切再生されなかった。
   - 一方、その後に「配達完了」を押したことで `fireAcousticWave`（半径400タイルのAI誘引ワールド音）のみが発火し、直後のゾンビ湧き呼び出しでクラッシュしたため、「ゾンビだけ近寄ってきてヘリ音や通知が鳴らない」という不可解な状態になっていた。

---

## 2. 原因の調査と特定

1. **`RadioTrader_HeliEvent.lua` の関数名不一致**:
   - 81行目では `local function spawnHordeZombies(lzX, lzY, lzZ)` と定義されていたが、176行目の呼び出し側が `enqueueHordeZombies(lzX, lzY, lzZ)`（初期設計時の旧命名）のまま残っていた。

2. **`RadioTrader_DebugServer.lua` のSP通知漏れ**:
   - `APPROACHING` / `COMPLETED` 変更時に `RadioTrader_ServerEngine.sendToClient` ではなく生の `sendServerCommand` を呼んでいたため、SP環境下でクライアントへ届いていなかった。

3. **バニラサウンド名の不整合と再生方式**:
   - `RadioTrader_ClientBridge.lua` で指定されていたサウンド名 `"RadioNoise"` や `"HeliLanding"` はバニラに存在しない架空の名前であった。
   - また、`getSoundManager():playUISound` のみではプレイヤー周辺のワールド/環境音（ヘリ音など）が耳に届きにくかった。

---

## 3. 実施した修正

1. **`RadioTrader_HeliEvent.lua`**:
   - 176行目を `spawnHordeZombies(lzX, lzY, lzZ)` へ修正。
   - これにより、音響ウェーブ → ゾンビスポーン → `deliverItems`（コンテナへの物資投下） → タイマーリセットが正常に完遂するようになった。

2. **`RadioTrader_DebugServer.lua`**:
   - `cmdForceState` 内の通知コマンドを `RadioTrader_ServerEngine.sendToClient` に置換。
   - SP環境でも接近警告および配達スキップ完了通知が確実にクライアントに届くよう修正。

3. **`RadioTrader_ClientBridge.lua`**:
   - バニラ公式のサウンド定義スクリプト（`sounds_meta.txt`, `sounds_object_radio.txt`）を調査し、バニラ実在サウンドへ刷新：
     - 接近警告: `"RadioNoise"` → `"RadioStatic"`
     - 配達完了: `"HeliLanding"` → `"Helicopter"`
   - `playSound` ヘルパーを `player:playSound`（プレイヤー位置からの環境音再生）優先 ＆ `playUISound` フォールバックの多層構造へ強化。

4. **全環境同期 & 静的検証**:
   - `tmp/sync_dirs.py` を実行し、`RadioTraderMod` から `RadioTraderMod_B42` および `mod` へ完全同期。
   - `scripts/check_mod_health.py` による全21ファイルの静的解析を実施（Critical Errors: 0, I18N Warnings: 0, ALL PASS）。

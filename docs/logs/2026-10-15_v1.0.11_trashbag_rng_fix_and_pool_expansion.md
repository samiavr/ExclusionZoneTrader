# Session Log: 2026-10-15 - 放出品「トレーダーのごみ袋」抽選バグ修正 ＆ プール拡充 (v1.0.11)

## 1. 概要 (Overview)
* **問題の背景**:
  ユーザーより「トレーダーのごみ袋（`Trader's Mystery Trash Bag`）を購入・開封すると、毎回【動物飼料】と【肥料】が確定で入っている」という報告を受理。
* **根本原因**:
  1. `RadioTrader_ItemsTable.lua` 内のカテゴリ重み付け抽選 (`pickCategory`) およびバニラルートテーブル選定 (`RollProceduralItem`) で使用されていた `ZombRandFloat(0, max)` が、ゲーム実行環境（Kahlua/LuaJava）において常に `0`（または極小値）を返していた。
  2. この結果、1回目のカテゴリ選定で先頭の `Farming` (農業) が `0 <= 15` で100%選ばれ、2回目の選定で除外後の先頭である `Livestock` (畜産) が `0 <= 10` で100%選ばれる決定論的バグが発生していた。
  3. アイテム選定でも同様にテーブル先頭の `Base.Fertilizer`（肥料）および `Base.AnimalFeedBag`（動物飼料袋）が常に選出され、中身が完全に固定化されていた。
* **対応内容**:
  1. `ZombRandFloat` を廃止し、PZ標準の堅牢な整数乱数 `ZombRand(max)` を用いた安全な累積重み付け抽選アルゴリズムに刷新。
  2. プレッパー超大当たり判定（約4.3%）およびバニラルート選定も同様に `ZombRand` ベースに統一。
  3. 各カテゴリの直指定アイテムプール（`cat.items`）を拡充（農業に種袋、畜産にバケツ・ハサミ、電子にアンプ・アルミ等）し、バニラルート失敗時のフォールバック処理を追加。
  4. 銃器売却査定表示における非ASCII文字（`[美品]` / `[使用感あり]`）のハードコードを解消し、`getTextOrNull` による多言語リソース（EN/JP）参照に統一。

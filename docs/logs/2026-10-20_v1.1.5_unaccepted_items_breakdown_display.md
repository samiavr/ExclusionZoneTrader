# 2026-10-20 v1.1.5 買取対象外アイテムの個数・内訳2行表示 ＆ コンテナ系3段階一律買取 ＆ 弾薬庫（Ammo）タブの実装

## 1. 概要と目的
1. **回収対象外物品の個数・内訳2行表示**:
   - ドロップボックス（LZコンテナ）内に買取対象外（回収時に削除されない）のアイテムが入っている場合、無線取引UIの下部通信ログに「何が何個対象外になっているか」の内訳を2行目に表示する機能を実装した。
   - 対象外の種類が多い場合にUIログ欄から横方向に文字が溢れないよう、項目単位で文字数およびフォント描画ピクセル幅を判定し、`... (他 N種)` で安全に省略する制御を導入した。
2. **コンテナ系（バッグ・ケース・箱・袋類）の3段階一律買取**:
   - 戦利品を詰めたバッグごとの一括納品や、補給物資の余りバッグ・クーラー・ゴミ袋のリサイクル処分を可能にするため、コンテナ系アイテム（`InventoryContainer`）を控えめな単価（実効 1 CR / 2 CR / 4 CR）で一律買い取る機能を実装した。
   - 安全対策として、バッグの中に回収対象外のアイテムが1つでも入っている場合は、バッグ自体を削除せず保護し、中の対象外アイテムのみを `[回収対象外]` として計上する仕組みを組み込んだ。
3. **`[弾薬] 弾薬庫 (Ammo)` タブおよび日替わり弾薬箱在庫プール（1日1回更新・0〜5箱）**:
   - 特定の口径の弾薬箱を指名買いできる `[弾薬] 弾薬庫` (`Ammo`) タブを左ペインに新設した。
   - 基準価格は口径別に `500〜800 CR` とし、在庫プールは1日1回（日付変更時のみ、50 CRリロール対象外）再抽選される `0〜5箱`（0箱 40%、1箱 30%、2箱 15%、3箱 8%、4箱 4%、5箱 3% で0・1箱が計70%の高確率）とした。

## 2. 変更ファイルと実装内容

### (1) `RadioTrader_ItemsTable.lua`
- **`RadioTrader_ItemsTable_AssessContainerItem(item, fallbackId)` の新設**:
  - **Tier 1（基準 2 CR → 実効 1 CR）**: ゴミ袋、ビニール袋、紙袋、麻袋・土嚢袋、ランチボックス、財布、ポーチ、筆箱など簡易袋・小箱類。
  - **Tier 2（基準 4 CR → 実効 2 CR）**: ダッフルバッグ、スクールバッグ、ハイキングバッグ、工具箱、救急箱、クーラーボックス、農産物箱など一般バッグ・ケース類。
  - **Tier 3（基準 8 CR → 実効 4 CR）**: 大型ハイキングバッグ、サバイバーバッグ、弾薬缶（AmmoBox）、プロテクティブケース、ガンケースなど大型バックパック・ハードケース類。
- **入れ子コンテナの安全保護（`scanInventory`）**:
  - コンテナの中身を先に再帰走査し、内部に回収対象外アイテム（`hasUnacceptedInside`）が存在する場合は、外側コンテナ自体の売却（`sellEntry`）をキャンセルして保護し、かつ外側コンテナ自体は `unacceptedItems` に重複追加せず内部の対象外アイテムのみをリストアップするよう制御。
  - また、ロット集計アイテム（生肉・切り身、卵、農作物）にも親コンテナ参照 `container = entry.container` を保持させ、バッグの中からでも確実に物理削除されるよう改善。
- **`RadioTrader_SummarizeUnacceptedItems(unacceptedItems)` の新設**:
  - `unacceptedItems` を品名別に集計し、個数が多い順（同数の場合は品名昇順）でソートした `{ { name = "品名", count = 個数 }, ... }` を返却。
- **銃器弾薬バッグ（`RadioTrader_Crate_Weapons`）のラインナップ完全網羅 ＆ ガンケース自動充填の追加**:
  - `distributionLists` に `"ArmyStorageGuns"`（軍用銃器庫）を追加し、`customItems` に M16（`Base.AssaultRifle`）やソードオフ・ショットガン2種（`Base.ShotgunSawnoff`, `Base.DoubleBarrelShotgunSawnoff`）を含む全14種の銃器本体と対応弾薬箱・マガジンを網羅。
  - `RadioTrader_ItemsTable_FillContainerItem` にガンケース系（`PistolCase`, `RevolverCase`, `ShotgunCase`, `RifleCase`, `GunCase`）の専用フォールバックを追加し、ケース種別に応じた銃本体＋弾薬箱＋マガジンのセットが確実に充填されるようにした。

### (2) `RadioTrader_ServerEngine.lua`

### (3) `RadioTrader_UI.lua`
- `formatUnacceptedDetails(unacceptedList, maxByteLen)` および `logUnacceptedItems(unacceptedList)` を実装：
  - 項目（`品名 x個数`）を順番に連結しながら、UTF-8バイト長（上限110バイト）および `getTextManager():MeasureStringX` によるUIログボックスの実描画幅（`logBox:getWidth() - 45` px）をチェック。
  - 上限を超える場合は `, ... (他 N種)`（英語: `, ... (+N more)`）を付与して省略。
- `onServerNotify` の `assessmentResult`、`sellSuccess`、`CMD_TRADE_ACCEPTED` にて、1行目のメインログに続けて2行目に黄色（`COLOR_WARN`）で内訳ログを出力。

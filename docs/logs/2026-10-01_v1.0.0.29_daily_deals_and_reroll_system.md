# 作業ログ: v1.0.0.29 バニラCrate日替わりスポット品目 ＆ CR消費周波数リロールシステム実装

- **実施日**: 2026-10-01
- **対象バージョン**: v1.0.0.29 (Phase 5-D)
- **対象コンポーネント**: `RadioTrader_ItemsTable.lua`, `RadioTrader_ServerEngine.lua`, `RadioTrader_UI.lua`, `RadioTrader_ClientBridge.lua`, `Translate/JP/UI.json`, `Translate/EN/UI.json`

---

## 1. 目的と概要
固定カタログ表示によるマンネリ化を打破し、余剰クレジット（CR）の優れた消費先（Sink）を提供するため、
バニラ（Project Zomboid B42）に存在する多種多様なCrate/Boxテーブルを活用した「日替わり特売・スポット入荷枠（Daily Deals）」および「CR消費による周波数再探索（リロール機能）」を実装。

---

## 2. 実装詳細

### 2.1 バニラCrate動的抽出・自動プライシング (`RadioTrader_ItemsTable.lua`)
- **8大ジャンルCrateテーブル定義 (`RadioTrader_DailyCrateCategories`)**:
  - 大工・建築 (`CrateCarpentry`, `CrateLumber`, `CrateTools`, `CrateToolsOld`)
  - 陶芸・石工 (`CratePottery`, `CrateClayBags`, `CrateClayBricks`, `CrateMasonry`)
  - 鍛冶・金属 (`CrateBlacksmithing`, `CrateMetalwork`, `CrateSheetMetal`)
  - 電気・電源 (`CrateElectronics`, `CrateBatteries`)
  - 動物・農業 (`CrateAnimalFeed`, `CrateFarming`, `CrateFertilizer`)
  - 医薬・救護 (`CrateHumanitarian`, `ArmyStorageMedical`, `MedicalClinicDrugs`)
  - 食品・穀物 (`CrateCannedFood`, `CrateFlour`, `CrateRice`, `CratePasta`)
  - 建材・骨材 (`CrateConcrete`, `CrateSandBags`, `CrateGravelBags`, `CratePaint`)
- **ウェイト逆算による価格・数量自動算出 (`calculateDailyItemPriceAndCount`)**:
  - 激レア品 (ウェイト <= 0.1): 1個限定, 800 CR (手斧・金床・貴重本等)
  - レア品 (ウェイト <= 1.0): 1個, 420 CR
  - アンコモン (ウェイト <= 10.0): 1〜2個, 240 CR
  - コモン資材 (ウェイト > 10.0): 木板10枚束(220 CR)、粘土・セメント・砂袋・鉄板4個(200 CR)、釘箱・ネジ箱・肥料2個(180 CR) 等の実用的なまとめ売り
  - 発電機・アリスパック等の大型高額機材への個別価格例外も完備
- **日替わり選定関数 (`RadioTrader_ItemsTable_RollDailyShop`)**:
  - 重複なしで6カテゴリをシャッフル選定し、`RadioTrader_Shop.Daily` に格納。
- **カテゴリタブ最上段への登録**:
  - `RadioTrader_ShopCategories` の最上段に `{ key = "Daily", label = "[Daily] Daily Deals" }` を追加。

### 2.2 サーバーサイドModData管理＆リロール (`RadioTrader_ServerEngine.lua`)
- `getOrUpdateDailyShop(forceReroll)`:
  - サーバー側 ModData (`RadioTrader_DailyState`) に `lastRolledDay` と当選アイテム配列を保存。
  - ゲーム内時間の日付変更 (`getWorldAgeHours() / 24`) で自動ローテーション。
- `rerollDaily` コマンド処理:
  - 所持クレジット 50 CR チェック → 引き落とし → 強制再抽選 → クライアントへ通知。
- `requestDailyShop` コマンド処理:
  - クライアント接続・UIオープン時のラインナップ同期。

### 2.3 クライアントUI＆演出 (`RadioTrader_UI.lua`, `RadioTrader_ClientBridge.lua`)
- 下部ボタンバーに `[🔄 周波数再探索 (50 CR)]` ボタン（幅210px）を新設。
- 残高不足時の警告音 (`AccessDenied`) とエラーログ表示。
- リロール成功時の無線ノイズSE (`RadioStatic`)、緑色HaloText (`+周波数再探索完了`)、UIログ表示、および `Daily` カテゴリの即時再描画。
- SP（シングルプレイヤー）環境での0ミリ秒即時反映ルーティング。

### 2.4 多言語翻訳
- `Translate/JP/UI.json` および `Translate/EN/UI.json` に `UI_RadioTrader_Cat_Daily`, `UI_RadioTrader_RerollBtn`, `UI_RadioTrader_Log_RerollSuccess`, `UI_RadioTrader_Halo_RerollSuccess`, `UI_RadioTrader_Err_NOT_ENOUGH_CREDITS_REROLL` を追加。

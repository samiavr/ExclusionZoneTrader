# 2026-10-01 v1.0.0.39 遠隔仮想ホード（Popman）と近接スポーンのハイブリッド配分システム

## 1. 概要
- 配達ヘリ飛来時の追従ゾンビについて、ロード済みエリアの「近接コーン状直接スポーン」と、未ロードの遠方（135タイル先）から行進してくる「遠隔仮想ホード（`ZombiePopulationManager.instance:createHordeFromTo`）」の配分システムを実装。
- サンドボックス設定 `HeliHordeRemoteRatio` により、遠隔ホードと近接スポーンの割合（0%〜100%）をプレイヤーが自由に調整可能に。
- ヘリが遠方から大量のゾンビを引き連れてきて、ヘリ到着前後に外周境界から実体化して一気に雪崩れ込んでくる臨場感・没入感を実現。

   - 万が一のAPI例外時は `directCount = count` に全数自動フォールバック。

# 2026-10-03 v1.0.0.58 投下要請TimedAction（10秒探りモーション）＆ LZ破損時地上ドロップ・1割衝撃損耗フォールバック

## 1. 概要
- **ユーザー要求**:
  1. 投下要請完了時のキャラクター吹き出し（`Say`）は無し。
  2. LZボックス操作時に、約10秒間何かごそごそ探るモーション（TimedAction）を挟む。
  3. 「ボックスが壊れたときになかみごと消えたり配達しっぱいになる？」という疑問に対し、ボックス破損・消失時でも物資が失われないフェイルセーフとして「LZの地面に直接木箱・農作物の箱を投下（ワールドドロップ）する」フォールバックを実装。
  4. 地面ドロップフォールバック時は、落下の衝撃として「鮮度や耐久が1割削れた状態」にする。

---

## 2. 実装詳細

### ① 投下要請TimedActionの新設 (`ISRadioTrader_RequestDropAction.lua`, `RadioTrader_ContextMenu.lua`)
- **アクション新設**:
  - `RadioTraderMod/42/media/lua/client/TimedActions/ISRadioTrader_RequestDropAction.lua`
  - 右クリックメニュー「`[Drop] Request Airdrop (Call Heli)`」選択時、即時パケット送信を廃止。
  - `luautils.walkAdj` でプレイヤーがボックス隣接マスへ移動後、約10秒間（500 ticks）しゃがんでボックス内を探るモーション（`Loot` / `LootPosition="Low"`）を実行。
  - 完了時に `sendClientCommand(CMD_REQUEST_DROP)` を発行。
  - **ユーザー指定の徹底**: 完了時のキャラクター発話（`character:Say`）は一切含めず、静かに無線パケットのみ送信。

### ② LZ破損時ワールドドロップ・1割衝撃損耗フォールバック (`RadioTrader_ServerEngine.lua`)
- **地上ドロップ判定**:
  - `RadioTrader_ServerEngine.deliverItems` において、`getLZContainer(player)` が `nil`（ボックス破壊・消失）だった場合でも即時リターン（配達消失）せず、`getLZCoords(player)` から `IsoGridSquare` を取得して地上ドロップモード（`isFallbackDrop = true`）に切り替え。
- **衝撃ダメージ適用 (`applyImpactDamage` / `applyImpactDamageToContainerItems`)**:
  - **耐久度 (Condition)**: 耐久値を持つアイテムは 1 割減少（`math.max(1, math.floor(curCond * 0.9))`、最低 1 ガード）。
  - **農作物・食品の鮮度 (Age)**: 腐敗開始時間（`offAge` / `offAgeMax`）の 10% 分エイジングを進める（`curAge + offAge * 0.1`）。
  - **中身への波及**: 農作物用の箱（`ProduceBox_Large`）、資材クレート（`Bag_DuffelBag`）、差し入れ（`Lunchbox`）の中身の全アイテムに対しても再帰的に 1 割削れ処理を適用。
  - **ワールドドロップ**: `sq:AddWorldInventoryItem(item, 0.5, 0.5, 0)` により、LZの地面に直接配置。

### ③ クライアント無線通知 ＆ 多言語対応 (`RadioTrader_ClientBridge.lua`, `UI.json`)
- 配達完了コマンド（`CMD_DELIVERY_DONE`）に `isFallbackDrop` フラグを連携。
- 地面投下時は、無線メッセージ末尾に専用警告アナウンス（`UI_RadioTrader_Radio_FallbackDropNotice`）を付加：
  - **JP**: `「【警告】投下ボックスが破損・消失していたため地面へ直接投下した。落下の衝撃で耐久や鮮度が1割損耗している、注意しろ。」`
  - **EN**: `"[WARNING] Drop box was missing/destroyed. Supplies air-dropped directly onto the ground. Condition and freshness reduced by 10%% from impact."`
- **静的解析での重大障害未然防止**:
  - `scripts/check_mod_health.py` の静的解析により、英語UI.json内の `%` リテラルが Java の `UnknownFormatConversionException` クラッシュを引き起こすリスクを即座に検知し、`10%%` にエスケープ修正。

# 作業ログ: spawnHordeZombies B42 APIエラーの完全修復 (v1.0.0.16)

**日付**: 2026-09-29
**対象コンポーネント**: RadioTrader_HeliEvent.lua（全環境）

## 1. 発生していた問題

「投下要請（DELIVERING）」を実行するたびに以下のエラーが発生し、アイテムが一切配達されなかった：

  ERROR: expected 3 arguments, got 2
    Lua((MOD:Radio Trader Mod)).spawnHordeZombies(RadioTrader_HeliEvent.lua:114)
    Lua((MOD:Radio Trader Mod)).trigger(RadioTrader_HeliEvent.lua:176)

spawnHordeZombies がクラッシュするため、deliverItems() および DeliveryTimer.reset() が実行されず、アイテムが永遠に届かない状態だった。

## 2. 原因の特定

- RadioTrader_HeliEvent.lua:114: cell:getChunkForGridSquare(spawnX, spawnY) -- 2引数
- B42のAPIシグネチャ: getChunkForGridSquare(x, y, z) -- 3引数が必要

## 3. 実施した修正

- getChunkForGridSquare 引数: (spawnX, spawnY) -> (spawnX, spawnY, spawnZ)
- 未ロード領域: pcall(cell:addZombieSpawnPos(...)) で安全スポーン
- ロード済み: pcall(IsoZombie.new) + pcall(pathToLocationF) で保護
